# Denti-Code Desktop — Project Vision

## Mission

Build a production-quality dental clinic management desktop application that is modern, professional, and easy to maintain.

## Core Principles

- **Kotlin Compose Desktop** — single codebase, native desktop experience
- **Material Design 3** — modern, accessible, consistent UI
- **Incremental development** — never redesign, always improve
- **Offline-first** — embedded SQLite, no server dependency
- **Clean Architecture** — separation of concerns, testable layers

## Target Users

- Dental clinic administrators
- Dentists and dental assistants
- Receptionists managing appointments and payments

## Key Features (Current)

- Appointment scheduling with full workflow (book → confirm → start → complete → cancel)
- Patient directory with search, filtering, and detail view
- Doctor directory with availability management
- Payment registration per patient
- Treatment tracking linked to appointments
- Inventory stock overview
- Procedure type catalog

## Non-Goals

- Multi-user real-time collaboration (single-user desktop app)
- Cloud synchronization
- Mobile apps
- Online booking portal
