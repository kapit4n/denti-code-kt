# Milestone 3 — Patient Workspace

## Goal

Transform Patient Detail into a complete clinical workspace: tabbed navigation, clinical history (medical + dental), timeline, documents, notes, prescriptions, follow-ups, treatments, payments and appointments.

## Features

- Tabbed workspace (Resumen, Historial clínico, Cronología, Citas, Pagos, Documentos, Notas, Recetas, Seguimientos, Plan de tratamiento)
- Medical history (allergies, conditions, surgeries, medication)
- Dental history (per-tooth records with diagnoses and treatments)
- Unified patient timeline (including treatment plans)
- Documents (native file picker copies to `~/.denti-code-kt/documents/<patientId>/`; open via OS viewer; physical delete; metadata-only docs marked)
- Free-form notes with pinning
- Prescriptions with status workflow
- Follow-ups with due-state tracking
- Treatment plans with phases, estimated cost and status workflow
- Clinical summary (treatments by status, active prescriptions, pending follow-ups, active plans)
- Real pending balance (treatments − payments)

## Deliverable

Complete patient management.
